# SHINOBIWAN LRC Maker

这是 `shinobione/lrc-maker` 的 SHINOBIWAN 定制版本，用于创建和同步 LRC 时间轴歌词。

- 应用：https://shinobione.github.io/lrc-maker/
- 仓库：https://github.com/shinobione/lrc-maker
- Issues：https://github.com/shinobione/lrc-maker/issues

当前版本保留核心 LRC 编辑与音频同步功能，并简化界面：不再显示元数据编辑区、不再自动插入 `[tool: ...]` 标签，也不再在界面中提供 GitHub Gist 功能。

完整说明请参阅 [README.md](./README.md)。
